# 时间轴与直接阅读 · 0.9.3

本次在上传的 Vite + React 工程上修改，保留已有首页、剧情播放器、地图、图谱、干员和媒体页面。

## 直接阅读

删除导航右侧、移动菜单、总览、图谱和页脚中的剧透模式入口，移除相关状态与保存逻辑。人物别名、关系、设定正文、图集和大图直接显示。旧浏览器曾保存的剧透等级不再被读取，也不会影响阅读；阅读进度、书签、音量和主题仍保留。

此变更开放项目内已经收录的内容，不会自动补入尚未导入的逐句剧情。播放器仍明确标示示例脚本或待导入状态，并提供对应资料入口。

## 时间轴的两层浏览

1. 总览中，每条竖线代表一个年份阶段。竖线上方是片段数量，下方显示年份和故事数量。
2. 点击阶段后，仅将该段局部拉宽；其他阶段仍以竖线保留，便于辨认上下文。
3. 展开区内每个剧情片段对应一个圆点，选中的圆点高亮。点击圆点会更新上方封面、剧情名、简介及阅读入口。
4. 下方同步展示该阶段的全部剧情名称，使用约19px的文字，并显示片段名与时间信息。名称与圆点双向同步，列表可展开或收起。
5. 点击“返回阶段总览”或按Esc退出局部展开；支持拖拽、滚轮横向平移、底部滑块、放大缩小与年份定位。聚焦轨道后，左右方向键切换阶段或片段。
6. 仍可按剧情类型、地区、系列与关键词筛选，并切换泰拉时间与国服实装顺序；切换排序保留当前剧情。

### 时间与归属规则

- 泰拉时间按记录中的年份区间分组。跨年片段会出现在每个相关阶段，同阶段内不重复同一片段。
- “故事”和“剧情片段”分别计数，同一活动可含多个片段。
- 年代未定或有争议的记录不强行插入精确年份轴，通过独立入口查看；切换实装顺序后仍按实装年份展示。
- 泰拉年内圆点表示当前资料中的排列顺序，不代表确切月份或日期。明示、推定和未定标签继续保留。
- 当前使用项目内已收录的32个故事、33个时间片段；并未宣称覆盖游戏全部剧情。剧情年代与既有示例数据的事实核对仍是独立内容工作。

## 封面自适应

上方左侧展示选中剧情的完整封面，使用等比例contain展示，并以暗化的同图背景填补长宽比例差异。横向活动横幅与纵向封面均不拉伸，也不会为了铺满容器裁掉标题。手机端改为封面在上、概览在下。

补齐8张经中文活动名称核对的官方宣传封面，当前32个故事均有本地对应资源；新增文件和逐项官方来源见 `docs/cover-sources-0_9_3.json`。图片加载异常时显示提示与文字封面。

## 参考与实现

参考[全历史首页](https://www.allhistory.com/)的“上方概览、下方分期、拖动与阶段定位”的信息组织。本项目的局部展开和剧情圆点为适配设计，不声称原站采用相同交互。

- `src/lib/timelineModel.js`：年份分组、跨年归属、局部布局和边界计算。
- `src/components/StageTimeline.jsx`：竖线、圆点、列表、滚动、缩放和键盘交互。
- `src/pages/Overview.jsx`：筛选、封面、概要与阅读入口的联动。
- `src/data/overviewMedia.js`：全部已收录故事的封面与出处。
- `src/styles/overview.css`：桌面与手机布局。

## 检查

`pnpm test` 检查跨年归属、未知日期、同日实装、片段去重、局部放大、边界以及所有故事的本地封面覆盖；`pnpm build` 检查生产构建。另在浏览器验证圆点与名称同步、封面切换、列表收起、年代未定、实装排序、筛选、手机布局以及全站移除阅读遮罩。
