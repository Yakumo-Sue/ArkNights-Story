# 首页体验优化 · 0.9.1

基于本次上传的 Vite + React 工程修改，保留其现有页面和数据结构。

## 首页开场

- 时长约 4.8 秒：巴别塔显影 → 撞击点裂纹扩散 → 镜片飞散 → 罗德岛徽记显现 → 徽记左移、标题及箭头展开。
- 裂纹由不规则的径向射线与两圈连线组成。桌面使用 45 片镜片，窄屏使用 27 片，共享顶点确保完整覆盖三角镜面。
- 镜片纹理在布局变化时预先裁切并缓存；每帧只计算速度、重力、三轴旋转、透视投影及透明度，避免逐帧模糊、渐变和大图重复裁切。高 DPI 渲染上限为桌面 1.6、窄屏 1.35。
- 动画与标题在图片解码后统一起步；时间使用 requestAnimationFrame 的实际时钟，不依赖帧数。窗口进入后台时暂停，回到前台接续播放，结束后停止帧循环。
- 保留跳过、重播、每会话仅自动播放一次；减少动态效果偏好下直接显示静态结果。资源异常会回到静态首页。
- 箭头以独立透明度动画出现，避免覆盖水平居中的 transform 后发生位置跳动。

涉及文件：`components/BabelIntro.jsx`、`components/OpeningCanvas.jsx`、`lib/fracture.js`、`lib/openingTimeline.js`、`styles/home.css`。

## 滚轮翻页规则

| 情况 | 行为 |
| --- | --- |
| 首页向下滚动 | 进入总览 |
| 主页面边缘的下一次明确手势 | 按首页、总览、设定、其他顺序翻页，可反向返回 |
| 页面或内部容器尚有内容可滚动 | 正常阅读，不触发页面跳转 |
| 同一次手势滚到页底 | 惯性尾部不跳页，停顿后再滚动才翻页 |
| 触控板小幅连续滚动 | 累计位移后触发，一次手势最多一页 |
| 时间轴、滑块、输入框、弹窗、导航与页脚 | 保持各自交互，不参与主页面翻页 |
| 横向滚动、Ctrl/Meta 缩放 | 不触发翻页 |
| 剧情播放器、地图等独立子页面 | 不启用主页面翻页 |

手势阈值为 84 CSS 像素，空闲分隔为 210 ms，翻页冷却为 950 ms；可在 `src/lib/wheelPagingCore.js` 调整。手机支持在可翻页边缘进行明确的纵向滑动；触摸取消或多指操作不触发翻页。
